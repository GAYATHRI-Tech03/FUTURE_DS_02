# FUTURE_DS_02 – Customer Churn Analysis

## 📌 Project Overview
This project focuses on Customer Retention and Churn Analysis using Power BI. The goal is to analyze customer churn patterns and understand the factors associated with customer churn.

## 🎯 Objectives
- Analyze total and churned customers.
- Calculate the customer churn rate.
- Compare churn across contract types.
- Analyze churn by internet service.
- Compare churned customers by payment method.
- Explore customer tenure and churn patterns.

## 🛠️ Tools & Technologies
- Power BI
- Microsoft Excel
- DAX
- Data Cleaning and Data Visualization

## 📊 Dashboard Highlights
- Total Customers
- Churned Customers
- Customer Churn Rate
- Retained Customers
- Churn vs Retention
- Churn Rate by Contract Type
- Churn Rate by Internet Service
- Churned Customers by Payment Method
- Customer Lifetime Trend

## 📁 Dataset
Telco Customer Churn Dataset from Kaggle.

Dataset Link:
https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## 🔍 Key Insights
- Compare churn rates across different contract types.
- Explore differences in churn across internet service categories.
- Examine payment methods among churned customers.
- Understand how customer tenure relates to churn.

*Note: These insights describe patterns in the dataset and do not necessarily establish the causes of churn.*

## 🚀 Project Outcome
Developed an interactive Power BI dashboard to explore customer churn patterns and support data-driven customer retention decisions.
